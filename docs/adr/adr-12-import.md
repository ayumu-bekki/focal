# ADR-12: 取り込み

- 状態: 確定（design.md v3、v3.19 で変更）

## 決定

**参照方式を基本**とする（登録したフォルダの写真は移動・コピー・変更しない）。
**例外として、SD カードなどからの取り込みだけ、ライブラリのルートの下に新しいファイルとしてコピーする**（`<ルート>/YYYY/YYYY-MM-DD/`、design.md 5.10 章）。カードの元ファイルは移動・削除・変更しない。

## 理由・補足

元ファイルへの書き込みは一切行わない。コピー先には新規作成だけで、既存のファイルは上書きしない（同名は `_1`、`_2` …）。

v3.19 の変更: v3 までは「参照方式のみ（コピーしない）」だったが、利用者の設計メモ（写真管理機能、3 章）でカードからの取り込みが要望されたため、利用者の承認を得て変更した。コピーは一時ファイルに書いて検証してから名前を変える。重複（取り込み済み）はスキップする。
