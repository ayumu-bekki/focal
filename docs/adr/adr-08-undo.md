# ADR-08: Undo

- 状態: 確定（design.md v3.4 で変更）

## 決定

**Undo スタックは core に置く**。写真ごと、**現像・ジオメトリ操作のみ**対象、セッション内のみ（永続化しない）。macOS では **Edit メニューの取り消す / やり直す（⌘Z / ⌘⇧Z）を core の Undo スタックに直接つなぐ**（`UndoManager` には登録しない。テキスト入力中は通常のテキストの Undo に渡す）

## 理由・補足

将来の各 OS の UI で同じ Undo 動作を共有するため。スライダーのドラッグ 1 回 = 1 エントリ。写真ごとのスタックは core が持つので、写真の切り替え時に `UndoManager` を作り直す処理が要らない（v3.4 で変更）
